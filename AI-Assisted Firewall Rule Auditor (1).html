Project Objectives 05

GENERAL OBJECTIVE

Build one low-cost, self-hosted web tool that audits and correlates security findings, and explains them to non-experts.

OBJ-01

Parse iptables, pfSense and Cisco ASA into one format

OBJ-02

Detect contradicting, duplicate and any-any rules

OBJ-03

Match software to public CVE data; flag unsupported versions

OBJ-04

Check certificate expiry, weak encryption and HTTPS

OBJ-05

Correlate findings by host; score Zero Trust compliance

OBJ-06

Rank host risk locally (Random Forest); flag insider weaknesses
